# Tauri + React 迁移第 31 步：主 DPS 窗口

## 本阶段范围

本阶段按用户提供的新版主窗口截图，一次完成主 DPS 窗口的 UI 与既有主流程接入。旧 egui
主窗口继续保留为行为对照；角色命中、队伍命中和深渊总览详情窗口仍属于后续独立迁移阶段。

## 契约与窗口边界

- Rust 继续持有实时抓包、回放、暂停缓冲、重置、新战斗轮次、历史记录和深渊半场状态；
- Tauri 提供版本 2 `MainDpsSnapshot`、有序十进制字符串 generation、100 ms 变更驱动 Channel
  和显式 command，React 不复制伤害、DPS、时停或历史计算；
- 版本 2 补充伤害归属、角色有效战斗时长和当前语言角色名；角色名在 Rust 契约边界根据
  `UiConfig.language` 从同一角色资源选择，语言切换通过 presentation revision 主动刷新；
- 主窗口成为桌面进程的所有者。Console 关闭时隐藏并保留页面状态，主窗口关闭时销毁 HUD、
  Console 和深渊数值窗口；
- 主窗口启动为隐藏状态，React 完成两帧绘制后再显示，避免首帧黑屏；窗口尺寸、位置、置顶、
  主题和透明度继续写回现有 `UiConfig`；
- “HUD”切换到独立 HUD 编辑窗口，“穿透”只切换主窗口鼠标穿透，并由既有全局热键恢复，
  两个操作不再混用；HUD 编辑栏新增回到主窗口的明确入口。

## 页面行为

- 自绘标题栏保留运行状态点、居中标题和最小化、最大化、关闭按钮；
- 标题栏显式调用 Tauri 原生拖动 API，并保持拖动权限最小化到主窗口；默认尺寸收紧为
  `670 × 560`，旧版 `670 × 692` 默认尺寸会在恢复时迁移到紧凑基线；
- 工具栏接入开始/停止、重置、新一轮、暂停/恢复、深渊行折叠、HUD、Console、置顶、穿透和外观；
- 战斗轮次支持实时数据与可回放历史快照，并用前后箭头和原生选择框切换；
- 摘要区展示队伍 DPS、总伤害、总受击和战斗时间；深渊激活时恢复层数、上半/下半选择及
  挑战成功状态；
- 队伍区恢复伤害归属条、属性图标、角色色条、头像、名称、命中、有效战斗时长、伤害、占比、
  DPS、受击和占比进度条；始终一名角色占一行，四行在可用高度内等高伸缩，队伍区不滚动；
  右键菜单支持复制和暂时隐藏，全部隐藏时提供恢复入口；详情按钮在对应窗口迁移前保持禁用；
- 空状态复刻新版截图的三步引导，接入实时抓包及 JSON/PCAPNG 原生文件选择回放；
- 错误使用顶部居中浮层，不改变页面布局。主数据 Channel 在空状态下低频探测游戏进程变化，
  实战状态只按 Rust revision 推送。

## 人工验收清单

入口：启动 Tauri 桌面程序，观察 `main-dps` 窗口。

1. 冷启动确认窗口在页面完成绘制后出现，无黑色首帧；标题栏拖动及三个窗口按钮正常；
2. 未进入战斗时对照新版截图检查工具栏、轮次、四项摘要、队伍标题和三步空状态；
3. 启动/退出游戏，确认第一步的绿色勾选在约一秒内主动更新；
4. 点击开始并产生伤害，确认归属条、属性图标、角色头像、排序、DPS、伤害、占比、命中、
   有效时长、受击和进度条随 Rust 快照更新；
5. 点击暂停后确认显示冻结，恢复后追上缓冲事件；点击新一轮确认当前轮次归档并清空实时轮；
6. 用前后箭头和选择框切换实时/历史轮次；深渊战斗中检查层数、上半、下半、挑战成功及折叠；
7. 停止抓包后分别导入 JSON 和 PCAPNG，确认先出现原生文件位置窗口，取消不产生成功状态；
8. 右键角色检查复制和隐藏，隐藏全部后点击“显示所有角色”；详情按钮保持禁用；
9. 检查置顶、穿透热键恢复、HUD 切换及 HUD 编辑栏返回主窗口；关闭 Console 只隐藏，关闭主
   窗口后进程正常退出；
10. 切换浅色/深色和透明度，并在窄窗口、宽窗口、100%、125%、150% DPI、多显示器下检查
    紧凑工具栏、500px 以下摘要两列/以上四列、四名角色固定单列且随高度等高伸缩、窗口位置
    恢复和文本截断；
11. 分别切换简体中文、日文和英文，检查主窗口、队伍角色名称、回放菜单、错误浮层和深渊
    半场文案同步更新。

桌面 UI 仍由用户人工启动验收；自动化验证不替代原生透明度、鼠标穿透、置顶、文件对话框、
多显示器、DPI 和真实抓包检查。
