# Tauri + React 迁移第 25 步：空幕页面功能接入

## 本阶段范围

本阶段完成空幕页面两步迁移的第 2 步。React 页面移除预览 fixture，改为消费 Rust 权威库存投影；
筛选仍是前端只读显示状态，装备规则、配装校验、Drive Calculator 文件、原生文件对话框和 Mod
Plugin 事务继续由 Rust 执行。

## 契约与数据流

- `core::empty_curtain` 集中一键配装选择和 Drive Calculator JSON 构造，旧 egui 与 Tauri 复用同一规则；
- Tauri 提供版本 2 的空幕快照，UID 保留 slot/serial，generation 和时间戳跨 JS 使用十进制字符串；
- 装备快照包含本地化名称、图标、类别、品质、等级、锁定/弃置、装备角色、位置、主副属性和套装效果；
- 100 ms 变更驱动 Channel 在订阅后立即发送完整快照；库存和角色映射事件现在会推进各自的专用
  generation，随后按库存代次或 Plugin 操作代次主动合并更新，不依赖页面重进或手动刷新；战斗 hit
  不会触发整份库存重复序列化；
- typed client 对版本、UID、枚举、数值、列表和详情上限执行边界校验；`Activity` 隐藏页面时注销订阅。

## 已接入操作

- 使用 Windows 原生保存对话框导出 Drive Calculator 库存；
- 使用 Windows 原生打开/保存对话框导入、导出角色配装，并复用 Rust 配装文件校验；
- 角色一键配装、全部卸下；
- 单件锁定/解锁、弃置/恢复、卸下；
- 卡带选择角色后装备，驱动模块先查询该角色的兼容位置再装备或跨角色移动；
- Plugin 请求状态随 Channel 回传，命令、校验、文件和流错误使用顶部居中提示，不改变页面布局。
- 装备副属性按装备最大等级和副属性槽位数由 Rust 投影解锁等级；当前资源的四个槽位对应
  `+5 / +10 / +15 / +20`，仅未解锁词条显示锁定图标和强化等级，已解锁词条回归普通属性行；
- Canvas 中所有未解锁副词条的锁图标使用固定右侧列，不再随 `+5 / +10 / +15 / +20` 文本宽度漂移；
  单件详情中的弃置操作使用统一 i18n key，不再回退显示英文按钮。
- Canvas 卡片按协议上限预留六行属性空间；驱动块的两条主词条与四条副词条全部显示，
  不再只截取第一条主词条，卡带的一条主词条布局保持不变。
- 筛选使用浏览器顶层模态浮窗，不参与装备页面布局，不会展开后推动工具栏或装备网格。
- 筛选角色直接使用 Rust 快照中的本地化名称，不再拼接角色 ID；角色与卡带支持名称搜索，
  角色、驱动块、卡带和属性选项均限制为分组内滚动，选项数量增长时不会无限撑高浮窗。
- 新增主词条筛选，同组多个主词条任一命中；副词条仍要求装备同时包含全部已选属性，
  不改变既有的分组间 AND 语义。
- 角色装备同样使用浏览器顶层模态浮窗；库存主体采用 HTML-in-Canvas：Canvas 负责 DPR-aware
  虚拟卡片绘制和命中测试，每帧只绘制可见行，HTML 保留筛选、角色操作、单件详情和无障碍键盘入口。
- Canvas 卡片从共享角色资源绘制装备者头像；窗口连续缩放时复用现有 backing store 即时重排，
  停止拖动 72 ms 后再按当前 DPR 锐化，避免每个尺寸事件都分配整张高分辨率位图。
- Console WebView 使用 Tauri/Wry 原生 auto-resize，在原生窗口事件处理中直接更新 GPU 合成表面；
  不再为每个 `Resized` 事件额外排队一次 `set_size`，避免快速缩放时尺寸滞后和重复 COM/窗口更新。
- 库存 Canvas 改为带上下两行超扫描的窗口化位图；普通滚动由 WebView2 GPU 合成器直接移动
  已绘制表面，仅在视口接近缓冲区边缘时重绘下一窗口，不再每滚动一个像素测量和绘制文字。
- 保持 WebView2 默认同步 Canvas 合成路径；透明卡片画布不请求 `desynchronized` 上下文，避免部分
  Windows/WebView2 GPU 驱动组合将透明区合成为黑色并降低文本栅格质量。
- 修正库存区原先由 `min-h-full` 与卡片最小高度共同撑开外层页面的问题：页面内容固定为可用高度，
  只允许装备 Canvas 容器滚动，保证 `clientHeight` 是真实视口而不是全部 331 件卡片的总高度，
  超扫描和虚拟绘制因此实际生效。
- 鼠标悬停描边从基础 Canvas 绘制中拆出为单个 HTML 内描边合成层；跨卡片只更新一次
  `translate3d`；命中检测直接使用专用 spacer 的内容坐标，不缓存会被祖先滚动改变的屏幕坐标；
  描边使用与 Canvas 相同的 12 px 外形，滚动开始时直接隐藏且不重绘整块超扫描 Canvas。

## 人工验收清单

入口：启动 Console，点击侧栏“空幕”。

1. 无抓包数据时显示空状态；开始抓包或导入含库存的回放后，装备卡片、角色、属性、套装和状态实时出现；
2. 验证角色显示本地化名称而非 ID，按角色名称和卡带名称搜索，并按角色、驱动块、卡带套装、
   品质、主词条和多个副词条筛选；多个主词条为 OR，分组间为 AND，副词条要求全部命中；
   大量选项只在各自分组内滚动；打开筛选时应浮在页面上方，调整条件不改变背景页面尺寸和滚动位置；
3. 对比卡带和驱动块，确认卡带显示一条主词条，驱动块完整显示两条主词条和四条副词条；再对比 `+1 / +5 / +10 / +15 / +20` 装备，确认未解锁副属性显示锁和门槛，四行锁图标位于同一列，已解锁副属性不再显示门槛或状态装饰；打开详情确认“弃置/恢复”随当前语言显示；
4. 点击“导出驱动计算器”，确认出现原生保存位置选择；取消不报成功，保存后 JSON 可由现有计算器读取；
5. 打开“角色装备”，确认独立浮窗不改变库存画布尺寸和滚动位置，并验证原生导入/导出对话框、一键配装和全部卸下；
6. 点击 Canvas 装备卡片打开 HTML 详情浮窗并验证锁定、弃置、卸下；卡带可选择角色装备，驱动模块必须选择 Rust 返回的兼容位置；
7. Plugin 未连接、忙碌、拒绝或返回错误时，顶部提示不挤占内容；操作完成后库存随抓包同步，不做前端乐观改写；
8. 在 Settings、History、Timeline、Skills、空幕和 Mod Studio 间反复切换，确认订阅被清理并在返回时立即恢复完整快照；
9. 将窗口调整为 760、900、1100、1440 像素，并在 100%、125%、150% DPI 下检查工具栏、角色面板、筛选和卡片管理区无横向溢出；
10. 切换简体中文、日文和英文，核对资源名称、属性、套装、文件和错误文案；
11. 使用 331 件及接近 4096 件边界数据快速滚动和连续切换筛选，确认只有装备区自身出现滚动条，滚动主要复用超扫描位图，跨缓冲区时无空白跳变，装备者头像正确出现且数据变化在 100 ms 合并窗口后主动出现；
12. 将鼠标停在装备区内滚动后连续跨行悬停，确认描边始终贴合鼠标所在卡片、圆角与卡片一致，且不会落后整行；
13. 从最窄窗口持续快速拖到宽窗口再缩回，确认 WebView 客户区和列数连续跟随、拖动期间不出现黑边、冻结或约半秒停顿，停止后文字与图片按当前 DPI 恢复锐利；
14. 与旧 egui 空幕页对照筛选、导出格式、配装验证、兼容位置和 Plugin 操作结果。

桌面 UI 仍由人工启动验收；自动化验证不替代原生文件对话框、Plugin IPC、窗口缩放和 DPI 检查。
