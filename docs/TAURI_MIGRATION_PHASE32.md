# Tauri 迁移第 32 步：新旧行为差异收口

## 范围

本步只收口第 31 步主 DPS 窗口及其已有辅助窗口与旧 egui 基线之间已确认的行为差异，
不删除 egui 对照入口，也不改动抓包解析、战斗归并、历史格式或更新协议。

## 已收口差异

### 会话与抓包生命周期

- `Pause` 冻结主窗口、HUD、时间线、技能、封包、空幕与命中详情所消费的同一份 Rust
  展示快照；Rust 抓包仍继续接收数据，界面以有序代次显示暂停期间累计的事件和调试封包数，
  `Resume` 一次切回最新状态。
- 查看历史轮次后，只有新的实时 outgoing hit 才自动回到实时轮次；普通状态刷新不会抢走历史选择。
- Start、Reset、文件选择导入、Ctrl+O、Console 命令面板导入和 `.pcapng/.json` 拖放统一使用
  “替换当前会话”确认语义。确认后会先停止活动任务，再开始新任务；取消保留当前统计。
- 空闲 Reset 保留 5 秒单次 Undo；活动任务 Reset 先停止任务并清空，不提供可能恢复到活动任务中间态的 Undo。
- Reset、重新开始和回放导入都会清理暂停/历史投影，确保新会话从实时页开始。

### 首次引导与通知岛

- 首次打开主窗口时显示四步引导：游戏进程、抓包设备、穿透恢复快捷键和 HUD 预设。
- 完成或跳过后复用 `UiConfig.onboarding_done`；步骤只保留在当前进程，避免为中间态新增持久化字段。
- 通知岛使用独立 `notification-island` Tauri 窗口，支持设置中的显隐和横向偏移、自动关闭以及
  Reset Undo；通知内容使用稳定 message key 并复用共享中日文资源。

### 窗口、布局和快捷键

- 角色命中详情与队伍命中详情分别使用 `character-details`、`team-details`，各自保留请求状态、
  尺寸和位置；深渊数值窗口也恢复独立尺寸和位置。
- Combat / Review / Research 布局预设现在会实际协调 HUD 穿透、Console 页签、深渊窗口和详情窗口，
  而不只保存密度或 HUD 预设。
- 深渊预测队伍增加“导入当前队伍”；仍由 Rust 从当前权威战斗状态生成队伍，不在 React 复制规则。
- 主窗口补齐 Ctrl+O、Ctrl+K、F12、Tab 与文件拖放；全局开始/重置快捷键在需要替换活动会话时
  会唤起主窗口确认框。

## 契约边界

- 主 DPS 契约提升为 v3，新增暂停积压、会话确认和首次引导字段；JS 不安全计数继续使用十进制字符串。
- 通知岛使用独立 v1 DTO；命中详情窗口继续共用同一详情 DTO，但窗口 label 决定角色或队伍请求槽。
- 所有业务状态仍由 `AppState`、`LiveCaptureService` 和既有 Rust reducer 持有；React 只展示和发出意图。

## 人工验收清单

1. **暂停**：实时战斗中点击 Pause，核对主窗口、HUD、时间线、技能、封包和详情均保持同一时刻；
   继续战斗后积压计数增加，Resume 后一次显示最新结果。
2. **历史返回**：选择历史轮次并等待普通状态刷新，选择不变；产生新的 outgoing hit 后自动回到 Live。
3. **确认与撤销**：有统计时测试 Start、Reset、Ctrl+O、命令面板 Import、拖放导入的取消与确认；
   空闲 Reset 后分别点击通知岛 Undo 和按 Ctrl+Z，并确认 5 秒后撤销失效。
4. **首次引导**：用 `onboarding_done=false` 启动，检查四步信息、Back/Next/Skip/Finish、三种 HUD 预设，
   再次启动时不重复显示。
5. **通知岛**：切换设置开关和横向偏移；检查中、日文，成功/错误文案，自动关闭和置顶，不抢输入焦点。
6. **布局预设**：依次应用 Combat、Review、Research，核对 HUD、穿透、Console 的 Timeline/Packets 页签、
   深渊和两个详情窗口的显隐。
7. **窗口独立性**：同时打开角色详情和队伍详情，分别移动和缩放后关闭再打开；深渊数值窗口同样验证。
8. **深渊队伍**：当前战斗存在角色时分别导入上半/下半，确认替换目标半场且另一个半场不变；空数据时显示错误。
9. **显示环境**：在窄窗口、100%/125%/150% DPI、多显示器和显示器拔插后检查位置恢复、标题栏、
   loading/empty/error、透明通知岛以及中日文最长文案。

本步没有启动桌面 UI；以上项目保留给人工对照旧 egui 界面验收。
