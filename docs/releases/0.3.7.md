# NTE DPS TOOL v0.3.7

## 简体中文

### 主要更新

- 使用 React 替换 egui 作为桌面 UI，大幅降低运行时内存占用。
- 新增 Mod 市场，可从市场下载 Mod，为软件扩展更多功能。

### Issue 修复

- [#30](https://github.com/kongbaiz/nte-dps-toolkit/issues/30)：查看历史记录时，新的伤害会自动返回实时数据；同类深渊记录切换时会保留当前上／下半层选择。
- [#31](https://github.com/kongbaiz/nte-dps-toolkit/issues/31)：移除大型 PCAPNG 回放可能触发异常的 egui/wgpu 渲染路径，并对回放事件流进行有界处理。
- [#32](https://github.com/kongbaiz/nte-dps-toolkit/issues/32)：历史记录显示、排序和文件名改用首条伤害或受击记录的时间，不再使用导入或保存时间。
- [#34](https://github.com/kongbaiz/nte-dps-toolkit/issues/34)：保存并恢复各窗口的位置，包含副显示器坐标。
- [#36](https://github.com/kongbaiz/nte-dps-toolkit/issues/36)：使用伤害记录附近的角色证据修正多角色数据中的伤害归属。
- [#37](https://github.com/kongbaiz/nte-dps-toolkit/issues/37)：修正服务端 HP 同步值被误计为额外伤害的问题，仅在匹配唯一明确时合并或校准伤害。
- [#38](https://github.com/kongbaiz/nte-dps-toolkit/issues/38)：Mod 工坊支持手动选择游戏安装目录，可用于台服等非标准安装位置。

## English

### Highlights

- Replaced egui with React for the desktop UI, significantly reducing runtime memory usage.
- Added the Mod Market, where Mods can be downloaded to extend the application with more features.

### Issue fixes

- [#30](https://github.com/kongbaiz/nte-dps-toolkit/issues/30): New damage now returns the view from history to live data, while switching between comparable Abyss records preserves the selected half.
- [#31](https://github.com/kongbaiz/nte-dps-toolkit/issues/31): Removed the egui/wgpu rendering path that could fail during large PCAPNG replays and bounded the replay event pipeline.
- [#32](https://github.com/kongbaiz/nte-dps-toolkit/issues/32): History display, sorting, and file names now use the earliest damage or incoming-hit timestamp instead of the import or save time.
- [#34](https://github.com/kongbaiz/nte-dps-toolkit/issues/34): Window positions are now saved and restored, including coordinates on secondary monitors.
- [#36](https://github.com/kongbaiz/nte-dps-toolkit/issues/36): Damage ownership in mixed-character data is corrected using character evidence adjacent to each damage record.
- [#37](https://github.com/kongbaiz/nte-dps-toolkit/issues/37): Fixed server HP synchronization values being counted as extra damage; merging or calibration now occurs only for a single unambiguous match.
- [#38](https://github.com/kongbaiz/nte-dps-toolkit/issues/38): Mod Studio now supports manually selecting the game installation directory for Taiwan and other non-standard installations.

## 日本語

### 主な更新

- デスクトップ UI を egui から React に置き換え、実行時のメモリ使用量を大幅に削減しました。
- Mod マーケットを追加し、Mod をダウンロードしてアプリの機能を拡張できるようになりました。

### Issue の修正

- [#30](https://github.com/kongbaiz/nte-dps-toolkit/issues/30)：履歴表示中に新しいダメージを検出するとリアルタイム表示へ戻り、同種の深淵履歴を切り替えても選択中の前半／後半を維持するようにしました。
- [#31](https://github.com/kongbaiz/nte-dps-toolkit/issues/31)：大容量 PCAPNG の再生時に異常を起こす可能性があった egui/wgpu の描画経路を削除し、再生イベント処理を上限付きにしました。
- [#32](https://github.com/kongbaiz/nte-dps-toolkit/issues/32)：履歴の表示、並び順、ファイル名に、インポート時刻や保存時刻ではなく最初の与ダメージまたは被ダメージ時刻を使用するようにしました。
- [#34](https://github.com/kongbaiz/nte-dps-toolkit/issues/34)：各ウィンドウの位置を保存・復元し、サブモニター上の座標にも対応しました。
- [#36](https://github.com/kongbaiz/nte-dps-toolkit/issues/36)：各ダメージレコード周辺のキャラクター情報を使用し、複数キャラクターが混在するデータでのダメージ帰属を修正しました。
- [#37](https://github.com/kongbaiz/nte-dps-toolkit/issues/37)：サーバー HP の同期値が追加ダメージとして誤集計される問題を修正し、一意に対応付けられる場合のみダメージを統合または補正するようにしました。
- [#38](https://github.com/kongbaiz/nte-dps-toolkit/issues/38)：Mod 工房でゲームのインストール先を手動選択できるようにし、台湾版などの標準外の配置に対応しました。
