# NTE DPS TOOL v0.4.4

## 简体中文

### 主要更新

- 抓包伤害统计改为使用服务器结算结果，请求数据只用于补充已匹配记录的信息。无法确认的字段保留未知，解析不可用时明确提示，不回退到估算伤害。
- 修复覆纹归因、独立命中结算及装备分片时钟处理，完善迟到信息更新后的战斗记录与时间轴同步。
- 新增独立的 UE Tools 插件数据源，与抓包模式分开使用；切换来源时先停止采集，保留当前记录，不自动开始下一场。
- Mod 市场支持管理宿主、Loader、驱动及功能插件；使用已编译组件，移除旧脚本编辑器和旧加载器入口。
- 新增角色账号快照、角色配装展示和逐击快照详情；缺失或未验证的角色属性、暴击及效果信息保持未知。
- 完善插件模式下的深渊上下半场、当前半场重开与整层重开处理，避免将当前半场重开误作整层清空。
- 调整控制台、设置及时间轴布局，刷新角色、装备和技能资源。
- 统一核心、桌面壳和前端版本为 0.4.4。

### 使用与兼容性说明

- 默认仍为抓包模式。自动伤害解析仅支持当前已验证的协议布局；不支持的流量会显示解析状态，不以推测值填补。
- 插件模式需要兼容的 UE Tools 宿主及插件。组件安装完成不代表已经加载；旧插件缺少必要能力时会明确拒绝开始采集，不会自动切回抓包。
- 插件在游戏进程内运行，存在兼容性及账号风险；启用前请阅读界面提示。
- 多语言词条更新暂缓，本次说明仅提供简体中文。
