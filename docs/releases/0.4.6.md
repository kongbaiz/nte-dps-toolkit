# NTE DPS TOOL v0.4.6

## 简体中文

### 新增与优化

- **插件更新提醒**：Mod 市场入口、分类和插件卡片新增更新红点，方便查看已安装组件的可用更新。
- **代理卸载**：代理模式新增卸载按钮，关闭游戏后即可操作，保留已下载组件、个人设置和无关文件。
- **加载失败提示**：细化 Loader 的错误信息，显示失败阶段和错误码，方便排查加载问题。
- **控制台整理**：精简插件功能和维护入口，移除不再公开提供的 Network 功能页及过期说明；已安装插件仍可加载和卸载。
- **多语言完善**：补齐简体中文和日文翻译。

### 问题修复

- 修复抓包时丢失中间分片后，该连接无法继续更新伤害数据的问题（[#62](https://github.com/kongbaiz/nte-dps-toolkit/issues/62)）。
- 清理旧加载器相关的无效代码。

### 资源更新

- 更新至 **CN 1.4.13** 游戏资源，同步角色、技能、环合和深渊数据。
- 更新技能归属及特殊伤害数据。

## English

### New and improved

- **Plugin update indicators**: Added update dots to the Mod Market entry, categories and component cards to highlight available updates for installed components.
- **Proxy removal**: Added an uninstall button for proxy mode. Close the game before removing the proxy; downloaded components, personal settings and unrelated files are retained.
- **Clearer loading errors**: Loader now shows the failure stage and error codes to help diagnose loading problems.
- **Cleaner control panel**: Simplified plugin and maintenance controls, removed the retired public Network feature page and outdated descriptions, and retained loading and unloading controls for installed plugins.
- **Localization**: Completed missing Simplified Chinese and Japanese translations.

### Fixes

- Fixed damage updates stopping for a connection after a middle packet fragment was lost during capture ([#62](https://github.com/kongbaiz/nte-dps-toolkit/issues/62)).
- Removed unused legacy loader code.

### Resource updates

- Updated game resources to **CN 1.4.13**, including character, skill, Esper Cycle and Abyss data.
- Refreshed skill attribution and special-damage data.

## 日本語

### 新機能・改善

- **プラグインの更新通知**：Mod マーケットの入口・分類・コンポーネントカードに更新ドットを追加し、インストール済みコンポーネントの更新を見つけやすくしました。
- **プロキシの削除**：プロキシモードにアンインストールボタンを追加しました。ゲーム終了後に操作でき、ダウンロード済みコンポーネント・個人設定・無関係なファイルは保持します。
- **読み込みエラーの改善**：Loader の失敗段階とエラーコードを表示し、原因を調べやすくしました。
- **コントロールパネルの整理**：プラグイン機能とメンテナンス項目を整理し、公開を終了した Network の機能ページと古い説明を削除しました。インストール済みプラグインの読み込み・解除は引き続き利用できます。
- **多言語対応**：簡体字中国語・日本語の不足していた翻訳を補完しました。

### 不具合修正

- パケットキャプチャ中に中間フラグメントが失われると、その接続のダメージ更新が停止する問題を修正しました（[#62](https://github.com/kongbaiz/nte-dps-toolkit/issues/62)）。
- 使用されていない旧ローダーのコードを削除しました。

### リソース更新

- ゲームリソースを **CN 1.4.13** に更新し、キャラクター・スキル・異能連環・深淵データを同期しました。
- スキルの帰属と特殊ダメージのデータを更新しました。
