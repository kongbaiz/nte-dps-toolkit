# NTE DPS TOOL v0.4.5

## 简体中文

### 主要更新

- 恢复代理加载模式下的手动游戏目录选择，支持选择安装目录或包含 `HTGame.exe` 的 `Win64` 目录，保存后重启工具仍保留，也可切回自动检测。部署前重新校验所选目录，失效时停止，不回退到其他安装位置。
- 适配 `NTE_PluginTraining` 训练插件，提供木桩 Tab 轮盘开关、训练状态和操作状态查询；仅接入当前插件开放的木桩功能，不恢复已移除的训练室功能。
- 调整公开插件组件范围：Training 替代 Performance。Performance 不再通过 Mod 市场提供或安装；用户已有 DLL 不会被主动删除，仍可使用通用加载、卸载管理。
- 补齐 Combat 插件的帧率解锁、刷新与状态查询，以及快捷大招开关和状态查询；操作继续检查宿主身份、插件加载状态及已声明能力。
- 整理 Mod Workshop 的宿主连接设置、插件功能分区及诊断维护入口，完善连接和使用指引。
- 修复抓包和插件模式下黑羽“恶意”伤害未识别的问题。恶意按独立服务器结算类别记录，与同一技能的普通属性伤害分组区分，明细使用独立的原生跳字素材，不归入六种异能反应伤害。
- 修复插件模式下安魂曲的生命上限削减和生命上限缩放导致的额外扣血未显示的问题。分别记录上限削减与额外生命损失，不重复计入；只有既有规则与服务器 HP 见证完全匹配才采用派生数值，缺少证据时保持未知。
- 补齐日语界面的目录选择、插件功能、恶意伤害及 Mod Workshop 文案，恢复翻译覆盖门禁。
- 同步 Rust 核心、Tauri 桌面壳和前端版本为 0.4.5。

### 使用与兼容性说明

- 选择或清除手动目录只保存部署目标，不会立即向游戏目录部署文件。代理部署仍需先关闭游戏，部署完成后重启游戏并检查宿主状态。
- 插件功能取决于已加载组件及其声明能力；下载或安装完成不等于已经加载，也不代表通过实机兼容性验证。旧插件缺少相关能力时，功能不会被强行启用。
- 恶意及生命上限缩放修复已使用实测抓包和原生证据进行离线回归；离线通过不代替新版本在游戏内的运行验收。
- 插件在游戏进程内运行，仍存在兼容性及账号风险，请阅读并确认界面提示。
