# NTE DPS TOOL v0.3.9

## 简体中文

### 主要更新

- 将 NTE Mods Plugin 的 SDK 缓存迁移为单文件压缩包 `NTE_SDK.bin`，减少大量小文件带来的存储和管理开销。
- 新增 Dumper7 SDK 生成与偏移扫描流程，并补充对应的原生测试入口。
- HUD 控制新增重置能力，并恢复主窗口透明度持久化行为。

### 问题修复

- NTE Mods Plugin 已整体恢复为 `codex/mod-effect-telemetry` 分支当前版本，包含该分支中的原生运行时与 SDK 缓存实现。
- 保持 SDK 缓存原子发布语义：新包生成或校验失败时不会覆盖已有可用缓存。
- 避免通知展示失败反向导致已成功操作被报告为失败。
- 应用层和脚本层的 effect telemetry 拆分仍按当前 PR 其它文件状态处理；原生 NTE Mods Plugin 不再做独立删改。

## English

### Highlights

- Moved the NTE Mods Plugin SDK cache to the single compressed `NTE_SDK.bin` package to reduce small-file storage and management overhead.
- Added Dumper7 SDK generation and offset-scanning support with native regression test entry points.
- Added HUD reset controls and restored persisted main-window opacity behavior.

### Issue fixes

- Restored the complete NTE Mods Plugin to the current `codex/mod-effect-telemetry` branch version, including that branch's native runtime and SDK cache implementation.
- Preserved atomic SDK-cache publication so a failed generation or validation cannot overwrite an existing usable package.
- Prevented notification-display failures from turning otherwise successful actions into failures.
- App- and script-layer effect telemetry separation remains governed by the rest of this PR; the native NTE Mods Plugin is no longer selectively modified.

## 日本語

### 主な更新

- NTE Mods Plugin の SDK キャッシュを単一の圧縮ファイル `NTE_SDK.bin` に移行し、多数の小さなファイルによる保存・管理コストを削減しました。
- Dumper7 による SDK 生成とオフセットスキャンを追加し、対応するネイティブ回帰テストの入口を追加しました。
- HUD のリセット操作を追加し、メインウィンドウの透明度設定の永続化を復元しました。

### Issue の修正

- NTE Mods Plugin 全体を `codex/mod-effect-telemetry` ブランチの現行版へ復元し、そのブランチのネイティブランタイムおよび SDK キャッシュ実装をそのまま反映しました。
- SDK キャッシュのアトミックな公開を維持し、新規生成または検証に失敗しても既存の利用可能なキャッシュを上書きしないようにしました。
- 通知表示の失敗によって、既に成功した操作まで失敗として扱われる問題を防止しました。
- アプリ層・スクリプト層の effect telemetry 分離は PR 内のその他のファイル状態に従い、ネイティブ NTE Mods Plugin には選択的な変更を加えません。
