# NTE DPS TOOL v0.4.1

## 简体中文

### 主要更新

- 新增 `nte-mod-loader` 备用加载方式。当代理 DLL 无法被游戏加载时，可通过控制台直接启动 Loader，无需把 Loader 放入游戏目录。
- Mod 工坊现在明确区分“代理加载（推荐）”和“Mod Loader（备用）”，并会记住上次选择的加载方式。
- 风险提示调整为仅在首次启用 Mod 时确认一次，确认结果会保存在配置文件中。
- 关闭 Mod Loader 时会同步结束本次会话中已注入的游戏启动器，避免启动器残留注入状态。
- 移除了无实际功能的“快速上手”区域，并压缩了 Mod 工坊顶部控制区。
- 适配手动映射加载场景，修复插件 TLS、模块路径、可执行内存范围及 SDK 缓存处理问题。
- 延后偏移解析直至游戏引擎模块就绪，并保留失败后的节流重试，提高早期注入场景下的稳定性。
- 发布流程新增 Mod Loader 的 Release x64 构建、测试、运行库依赖检查及打包。
- 更新版本号为 0.4.1。

## English

### Highlights

- Added `nte-mod-loader` as a fallback loading method when the proxy DLL is not loaded by the game. The Loader stays beside the desktop application and does not need to be copied into the game directory.
- The Mod Workshop now distinguishes between recommended proxy loading and the fallback Mod Loader, and remembers the last selected method.
- The Mod risk warning is now confirmed only on first enable, with the acknowledgement persisted in the configuration file.
- Stopping the Mod Loader also terminates game launchers injected during that Loader session, preventing residual injected state.
- Removed the non-functional Quick Start section and compacted the Mod Workshop controls.
- Adapted the plugin for manual mapping, including fixes for TLS use, module-path lookup, executable-memory validation, and SDK cache handling.
- Offset resolution now waits for the game engine module to become ready and retries failures with throttling for improved early-injection stability.
- The release workflow now builds, tests, validates runtime dependencies, and packages the x64 Release Mod Loader.
- Updated the version number to 0.4.1.

## 日本語

### 主な更新

- プロキシ DLL がゲームに読み込まれない場合の代替手段として `nte-mod-loader` を追加しました。Loader はデスクトップアプリと同じ場所に置かれ、ゲームディレクトリへコピーする必要はありません。
- Mod ワークショップで推奨のプロキシ読み込みと代替の Mod Loader を明確に分け、最後に選択した方式を保存するようにしました。
- Mod のリスク警告は初回有効化時に一度だけ確認し、確認結果を設定ファイルへ保存するようにしました。
- Mod Loader を停止すると、そのセッションで注入されたゲームランチャーも終了し、注入状態が残らないようにしました。
- 機能のなかった「クイックスタート」を削除し、Mod ワークショップ上部の操作領域をコンパクトにしました。
- 手動マッピングに対応し、TLS、モジュールパス、実行可能メモリ範囲、SDK キャッシュ処理を修正しました。
- ゲームエンジンのモジュールが準備できるまでオフセット解析を待機し、失敗時は間隔を空けて再試行することで、早期注入時の安定性を改善しました。
- リリース処理に Mod Loader の Release x64 ビルド、テスト、ランタイム依存関係検査、パッケージングを追加しました。
- バージョン番号を 0.4.1 に更新しました。
