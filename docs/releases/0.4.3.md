# NTE DPS TOOL v0.4.3

## 简体中文

### 主要更新

- 修复群怪场景下伤害记录不正确的问题。
- 修复达芙蒂尔额外倾陷伤害的错误分类。
- 修复窗口位置位于屏幕范围外的问题。
- 控制台新增快捷键板块，支持为常用按键绑定快捷键。
- 控制台侧边菜单支持收藏，可以收藏常用的功能板块。
- 首页的部分统计数值支持自定义开启或关闭显示。
- 覆纹伤害支持精准识别记录。
- 安魂曲 5 觉的削减最大生命值上限加入记录。
- 优化了部分文本描述。
- 更新版本号为 0.4.3。

## English

### Highlights

- Fixed incorrect damage records in multi-enemy encounters.
- Fixed the incorrect classification of Daffodill's additional Break damage.
- Fixed windows being positioned outside the visible screen area.
- Added a Shortcuts section to the console, with support for assigning shortcuts to commonly used controls.
- Added favorites to the console sidebar, allowing frequently used feature sections to be saved for quick access.
- Added options to show or hide selected statistics on the Home page.
- Added precise recognition and recording for Hexed damage.
- Added recording for the maximum HP reduction cap from Lacrimosa's fifth awakening.
- Improved several text descriptions.
- Updated the version number to 0.4.3.
