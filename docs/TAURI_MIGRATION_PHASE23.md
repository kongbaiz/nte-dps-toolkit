# Tauri + React 迁移第 23 步：技能页面功能接入

## 本阶段范围

完成技能页面两步迁移的第 2 步：保留第 22 步 React 页面，把预览 fixture 替换为当前抓包的
真实技能归因投影。本阶段不迁移其他 Console 页签，也不修改命中解析、技能归因、伤害聚合、
历史或更新协议。

## 数据与契约

- 新增 UI-neutral `core::skills`，直接复用 `summarize_skill_breakdown` 和深渊上下半命中集合；
- 投影包含总归因伤害、总命中、角色汇总、技能行和待映射诊断，不向 WebView 传输逐 hit；
- 角色名称、颜色和排序沿用 Rust 资源；技能显示名继续使用现有 ability/GE 本地化资源；
- 解析器产生的攻击类型和反应标签通过单一稳定 key 映射，egui 与 Tauri 共用该映射；
- Tauri Skills contract 版本为 1，generation、命中和诊断计数均用十进制字符串跨 JS 边界；
- 快照命令提供整场、上半和下半范围；Channel 最多每 100 ms 合并一次变更，并在新订阅时立即
  发送完整快照；
- React typed client 对版本、范围、有限数值、十进制字符串、颜色和列表上限进行边界校验；
- `useSkills` 持有订阅清理句柄，`Activity` 隐藏页面时停止 Channel，重新显示后恢复完整快照。

## 页面行为

- 页头移除界面预览标记，显示实时状态和整场/上半/下半范围切换；
- 首次读取显示骨架，无归因数据时显示空状态，命令失败显示错误和重试；
- Channel 错误使用顶部居中浮层，不改变页面布局，也不触发整页内容替换；
- 角色选择只筛选当前完整快照，Rust 权威状态保持只读；数据更新后若角色已消失，选择自动回到
  整队；
- 技能名称、分类、命中、伤害、占比、技术标识和待映射 GE 均来自真实投影。
- 技能行悬停或键盘聚焦显示角色、分类、伤害、命中、GA、GE 和 GE Index；
- 待映射 GE 提供逐项复制编号按钮，并显示复制成功或失败状态。

## 人工验收清单

入口：启动 Console，点击侧栏“技能”。

1. 未抓包时显示空状态；开始抓包并造成伤害后，角色与技能行在一个合并周期内出现；
2. 对照旧 egui 技能页核对整队归因伤害、技能项、待映射命中、候选方向和技能排序；
3. 进入深渊后切换整场、上半、下半，分别核对角色、伤害、命中和技能列表；
4. 点击角色后只显示该角色技能；持续抓包、重开或切换范围后选择状态合理保留或回到整队；
5. 展开待映射诊断，核对未知角色、候选方向、待映射技能和未映射 GE；
6. 在 Skills、Settings、History、Timeline、Mod Studio 间反复切换，确认返回 Skills 后快照完整，
   没有重复订阅和页面闪烁；
7. 在 760、900、1100、1440 像素宽度快速缩放，并检查 100%、125%、150% DPI；
8. 切换简体中文、日文和英文，核对角色名称、技能资源名、攻击类型、loading、empty 和 error；
9. 长时间抓包后检查技能列表滚动、悬停和角色切换响应。

UI 由人工启动验收；自动化验证不替代实战、窗口缩放、DPI 和旧界面对照。
