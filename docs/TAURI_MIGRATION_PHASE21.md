# Tauri + React 迁移第 21 步：时间线功能接入

## 本阶段范围

完成时间线两步迁移的第 2 步：保持 Rust 为事实源，将第 20 步的 React/Canvas 页面接入
真实战斗时间线，并启用数据相关控件。本阶段不迁移其他 Console 页签，也不修改抓包、解析、
伤害归属或更新协议。

## 数据与契约

- `core::timeline` 从现有 `CombatState::timeline` 或深渊上下半状态生成前端无关投影；
- 投影包含聚合 bucket、角色总伤害、角色 DPS、暂停区间、深渊事件标记和 5 秒空闲阈值分段；
- 角色名称和颜色使用已加载资源，缺失资源时使用记录名称和确定性颜色回退；
- Tauri Timeline contract 版本为 1，`generation` 与 bucket `hits` 使用十进制字符串；
- 快照命令提供首屏和重试，Channel 以 100 ms 为最大合并延迟，仅在抓包或展示代次变化后发送
  一份完整聚合快照；
- 统计间隔和团队/角色曲线模式写入现有 `UiConfig`，沿用原有范围校验与原子配置保存；
- React typed client 校验所有 IPC 输入后交给页面，订阅清理句柄由 `useTimeline` 的 Effect 持有。

## 页面行为

- 整场战斗、上半、下半切换会重新建立对应范围的订阅并立即获取完整快照；
- 统计间隔滑块拖动时只更新本地显示，释放、失焦或键盘操作完成后才保存并重算；
- 团队/角色曲线模式立即保存；角色图例仅改变前端高亮，不修改 Rust 权威数据；
- 无战斗数据时显示空状态；初次请求显示骨架；契约或命令错误显示错误信息和重试入口；
- Canvas 继续只负责密集几何，HTML 保留控件、标签、悬浮明细和无障碍摘要。

## 人工验收清单

入口：启动 Console，点击侧栏“时间轴”。

1. 未抓包时显示空状态；开始抓包并产生伤害后，摘要、曲线和 bucket 明细在一个合并周期内出现；
2. 切换“整场战斗 / 上半 / 下半”，分别核对整场与深渊半场数据；没有对应半场时显示空状态；
3. 拖动统计间隔到 0.2、1.0、2.0 和 10.0 秒，释放后采样数与曲线重算，重启程序后值保留；
4. 切换团队/角色曲线并重启 Console，模式保留；点击角色图例时其他曲线弱化，再次点击取消；
5. 在抓包持续更新时从 Timeline 切换到 Settings 或 Mod Studio，再返回 Timeline，确认日志/战斗
   窗口内的数据连续，且没有重复订阅造成的闪烁；
6. 在 820、1000、1280、1440 像素宽度快速缩放窗口，图表、悬浮卡和底部状态不被裁切；
7. 在 100%、125%、150% DPI 下确认 Canvas 清晰，指针对应 bucket 正确；
8. 简体中文、日文和英文下检查 loading、empty、error、范围、指标和事件标记；
9. 对照旧 egui 时间线核对总伤害、峰值 DPS、战斗时间、暂停区间数量、角色排序和战斗分段。

UI 由人工启动验收；自动化验证不替代窗口缩放、DPI 和长时间抓包检查。
