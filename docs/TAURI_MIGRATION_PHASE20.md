# Tauri + React 迁移第 20 步：时间线 UI

## 本阶段范围

时间线迁移严格拆成两步：

1. **迁移 UI（本阶段）**：复刻现有 egui 时间线的信息结构、响应式布局和图表交互表现；
2. **接入功能（下一阶段）**：定义 Rust 投影 DTO、typed command/Channel，并用真实战斗数据替换 UI 预览数据。

本阶段只改 React 展示层、导航、翻译和迁移文档。没有新增 Rust 业务规则、Tauri command、
Channel 或历史数据读取。页面使用明确的“界面预览 / 数据将在第 2 步接入”标识，避免把预览
数据误认为真实战斗结果。

## UI 迁移结果

- Console 侧栏启用“时间轴”，页面通过 React 19.2 `Activity` 挂载；隐藏时清理 Effect，
  返回时保留本地 UI 状态并重建 Canvas 生命周期；
- 保留 egui 时间线的信息层次：战斗范围、统计间隔、团队/角色曲线、四项摘要、战斗分段、
  角色图例、悬停明细、暂停区间、事件标记和保留窗口信息；
- 尚未接入 Rust 的范围、统计间隔、曲线模式和图例控件保持禁用；预览曲线仅支持不改变
  权威状态的悬停明细；
- 密集曲线、网格、暂停区间和标记由 Canvas 绘制；标题、按钮、图例、提示和无障碍摘要由
  HTML/React 持有；
- Canvas 使用 `ResizeObserver`、`requestAnimationFrame` 和 DPR backing store，窗口宽度或
  DPI 改变后按当前客户区重算，不固定桌面尺寸；
- 时间线表面增加 rAF 合并的指针聚光，图表使用 CSS 玻璃分层、渐变边界、曲线辉光、面积渐变、
  斜纹暂停区间、事件标签和首次进入揭示动画；
- 悬停时由 HTML 层提供时间游标、透镜、角色贡献条和毛玻璃详情卡，Canvas 同步高亮各角色采样点；
- 新增动效同时遵循系统 `prefers-reduced-motion` 和应用 `.reduce-motion` 设置；
- 布局在窄窗口中自动换行并将指标从四列降为两列；图表改为通过 Flex 消费内容区剩余高度，
  正常窗口优先完整显示底部状态，短窗口降低图表最小/最大高度并保留内部滚动兜底；
- 新增纯函数测试覆盖窄/宽窗口绘图区、指针到 bucket 的边界映射和高 DPI backing store。

## 第 2 步边界

功能接入时继续由 Rust 作为唯一事实源：

- Rust 投影当前战斗时间线摘要、角色曲线、暂停区间、事件标记和可选深渊分段；
- Tauri 使用稳定 DTO 与批量 Channel，不向 React 暴露 `CombatState` 或逐 hit 数据；
- React typed client 在边界校验版本、序列和数值，再替换本阶段的预览 fixture；
- 统计间隔、范围选择、拖拽选区、右键标记/缩放的真实操作在 Rust 契约接入后启用；
- 订阅在 `Activity` 隐藏时清理，重新显示后从完整快照恢复。

## 人工验收清单

入口：启动 Console，点击侧栏“时间轴”。

1. 页面显示“界面预览”和“数据将在第 2 步接入”，不会与实时结果混淆；
2. 对照旧 egui 时间线确认摘要、分段、图例、曲线、暂停阴影、标记和底部窗口信息均存在；
3. 团队/角色、整场/上下半、统计间隔和角色图例控件均可见且保持禁用；
4. 鼠标在预览曲线上移动时明细提示不越过图表右边界；
5. 在 820、1000、1280、1440 像素宽度快速拖动窗口，页面不横向溢出、不露黑边；
6. 在 100%、125%、150% DPI 下确认曲线清晰，Canvas 与指针位置一致；
7. 展开/折叠侧栏并在 Settings、History、Timeline、Mod Studio 之间切换，页面状态保留且无闪烁；
8. 简体中文、日文和英文下检查标题、按钮、指标和底部状态；
9. 深色/浅色主题下检查网格、曲线、暂停区间、标记和悬停卡片对比度。

本阶段验收通过后，再开始第 2 步功能接入。
